# Experiment Plan

- **id**: exp_delayaware_mpc_rm
- **status**: draft

## Hypothesis
如果将在 RoboMaster 自瞄的预测控制中显式建模多段时变视觉-机构-弹道延迟链（含时延估计与不确定性界），并据此设计延迟感知 MPC（相比：A. 当前 EKF 预测+Kt+B 经验前馈+PID；B. 未显式建模时延的 MPC），则在快速机动目标（直线/圆周/S 形/变速/遮挡）跟踪中，命中率提升且云台指向角误差 RMSE 下降。

## Dataset
1) 仿真：自建 RM 云台动力学+视觉流水线时延模型（时延真值可注入，含固定/时变 jitter 两种模式）；2) 真实平台：RoboMaster EP/自研步兵（或哨兵）云台 + 工业相机 + Jetson；目标为已知运动规律的小车/摆锤/装甲板模拟目标，用裁判系统或运动捕捉/编码器作为地面真值。预注册轨迹集与速度档位。

## Baseline
(1) RMVL 风格基线：EKF/KF 预测 + Kt+B 经验前瞻 + 串级 PID（社区默认）；(2) SHtech 风格基线：IESEKF 预测 + 无显式时变时延建模的 MPC；(3) 上界参考：零延迟理想控制（仿真中可注入，真实平台用运动捕捉离线补偿）。

## Method
保持检测/解算前级不变，仅替换‘预测+控制+补偿’模块；开发毫秒级时延测量协议（曝光→取图→检测→解算→串口→云台到位→开火→命中各环节时间戳）；MPC 采用延迟状态增广/输入延迟补偿（DT=10ms 量级，HORIZON≈1s，ADMM 或 OSQP 求解，报告 P99 求解耗时）；时延不确定性以界的形式进入鲁棒约束。

## Metric
主指标（预注册）：命中率（规定发弹数 N 的命中数/N，按裁判系统判定）与云台指向角误差 RMSE（相对地面真值）；统计检验：配对 t 检验/Wilcoxon，显著性水平 p<0.05 且报告效应量。次指标：脱靶量、时延估计误差、求解耗时 P99、目标丢失率。

## Ablation
A1：去掉时延建模（MPC 无延迟项）→ 量化延迟补偿贡献；A2：去掉预测直接瞄准 → 量化预测贡献；A3：固定延迟 vs 时变延迟注入 → 验证时变鲁棒性；A4：不同目标运动模型（CV/CT/车辆旋转）→ 验证模型选择影响；A5：与 SHtech 基线同前级对比 → 验证可复现性。

## Expected
时延感知 MPC 在快速机动与高时延抖动下命中率/跟踪误差显著优于两个基线，且 A1 消融显示延迟建模贡献为正；结果须在仿真与真实平台方向一致。

## Failure
若仿真中在 ≥3 个预注册轨迹类别上均未显著优于‘无时延建模 MPC’，或真实平台命中率提升不达预注册阈值（建议 ≥5 个百分点，最终以用户确认值/效应量下界为准），则判定假设不成立；若时延测量协议无法达到 1ms 级精度或地面真值缺失，则判定实验无效并回退重新设计。
