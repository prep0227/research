## 1. 系统架构（自研步兵自瞄）

```
┌─────────────── 感知层 ───────────────┐   ┌────────── 估计/预测层 ──────────┐
工业相机(曝光中点时间戳) → 取图 → 检测(YOLO/灯条) → 角点优化 → PNP解算
                                          │
                                          ▼
                    EKF/IESEKF 目标状态估计（CV/CT/车辆旋转模型）
                    输出：当前状态 + 任意未来时刻预测(均值+协方差)
                                          │
┌─────────────── 规划/控制层 ────────────▼───────────────────────────────┐
      延迟链模型（在线估计 τ_vision/τ_serial/τ_gimbal/τ_fire/τ_flight）
                    ↓
         延迟感知 MPC（状态增广输入延迟 + 预测参考 + 约束）
                    ↓
         发弹决策（fire window: 预测命中角误差 < 阈值）+ 弹道补偿
                    ↓
┌─────────────── 执行层 ────────────────┐
串口(2ms周期) → 电控 → 云台(编码器/IMU反馈) → 发弹 → 弹丸飞行
                    ↓
┌─────────────── 评估层 ────────────────┐
裁判系统命中 + 时间戳日志（延迟画像）+ 角误差日志
```

**关键设计决策**：把"目标预测"与"云台控制"从分离式（社区现状：预测器输出一个提前角，PID 去追）改成**一体化延迟感知 MPC**（预测参考直接进入 MPC 的滚动时域优化，输入延迟通过状态增广显式建模）。这是与 SHtech 2026 的差异化核心：SHtech 把延迟作为常量参数，我们显式建模**时变/不确定**延迟并做鲁棒处理与受控归因。

## 2. 延迟链建模与测量协议

### 2.1 延迟分解（真机须实测，社区参考量级仅作起点）

```
τ_total(t) = τ_cam(t) + τ_proc(t) + τ_serial(t) + τ_gimbal(t) + τ_fire(t) + τ_flight(t)
```

| 段 | 含义 | 社区参考量级（未核验） | 真机测量方法 |
|---|---|---|---|
| τ_cam | 曝光中点→图像进主机 Buffer | ~1–8ms | 工业相机 SDK 时间戳（曝光开始/结束） |
| τ_proc | 取图→检测→角点→PNP 解算 | ~10ms | 流水线逐级时间戳插桩（ns 级） |
| τ_serial | 指令主机→电控 | ~1ms | 回包/裁判系统链路时钟 |
| τ_gimbal | 电控收到→云台到位 | 20–200ms | 编码器/IMU 阶跃响应 63% 到位时间；随幅值/速度档变化 |
| τ_fire | 发弹信号→弹丸出膛 | 50–100ms | 光电/声学触发传感器或裁判系统 |
| τ_flight | 出膛→命中 | 50–250ms | 弹道模型解算 + 实测标定 |

### 2.2 时变与不确定性建模

- 每段延迟：`τ_i(t) = τ̄_i + δ_i(t)`，`δ_i(t)` 有界（`|δ_i| ≤ Δ_i`），用时间戳序列估计均值/方差/分布类型（如 Gamma / 均匀 / 高斯截断）。
- **延迟画像（latency profile）**：真机首步先测各段分布（每段 ≥200 样本），写入配置文件；仿真中可注入相同分布以复现。
- 时间基准：统一到裁判系统/晶振同步时钟，曝光**中点**作为测量时间戳（避免曝光区间偏差）。

### 2.3 在线延迟估计（方法贡献点之一）

- 视觉段：由"曝光时间戳 → 解算完成时间戳"逐帧记录，滑动窗估计 `τ_vision` 均值/分位数。
- 机构段：由串口指令时间 + 云台编码器到位判据（角速度过零 + 稳定窗口）估计 `τ_gimbal`。
- 不确定性界：取 P99 − 均值 作为 `Δ_i`，进入 MPC 鲁棒处理（约束收紧/管道），而不是把延迟当常数。

## 3. 目标运动建模与状态估计

- 状态：`x = [x, y, z, vx, vy, vz, θ, ω]`（装甲板中心 + 旋转角/角速度）；底盘运动学（全向轮 → 任意平移 + 旋转）。
- 运动模型库：
  1. **CV**：`x(k+1)=x(k)+v·dt`（直线/近似匀速）
  2. **CT**：恒定转率模型（圆周）
  3. **车辆旋转平移模型**（TJURM 模型二）：整车中心 + 装甲板绕车心旋转，适配 S 形/变速/旋转组合
- 估计器：EKF/IESEKF（非线性 PNP 测量、装甲板四点几何约束）；**延迟测量处理**：测量在 `t−τ_vision` 时刻有效 → 先按测量时刻更新，再传播到当前时刻（标准 out-of-sequence 处理）。
- 预测输出：任意未来时刻 `t+τ` 的目标方位（均值 `μ(τ)` + 协方差 `Σ(τ)`），供 MPC 参考与命中概率计算。

## 4. 延迟感知 MPC 公式化

### 4.1 云台模型（两轴解耦，内环速度环近似）

```
yaw(k+1)   = yaw(k)   + dt·yaw_rate(k)
yaw_rate(k+1) = yaw_rate(k) + dt·u_yaw(k − d_g)
pitch 同理
```
- `d_g = round(τ_gimbal/dt)`：输入延迟步数（**状态增广**：维护最近 d_g 个控制输入缓冲）。
- 控制输入为角加速度指令，约束：`|u| ≤ u_max`，`|Δu| ≤ du_max`（云台电机限幅）。

### 4.2 优化问题（滚动时域，DT=10–20ms，H=0.5–1s）

```
min_{u(0..H-1)}  Σ_{k=0}^{H-1}  e(k)^T Q e(k) + Δu(k)^T R Δu(k)
s.t. 增广动力学（含输入延迟）,
     |u(k)| ≤ u_max, |Δu(k)| ≤ du_max,
     e(k) = aim_point(t0 + k·dt) − g(k)     % 指向误差 vs 提前瞄准点
```
- 参考 `aim_point(t) = az/el( 预测目标在 t + τ_fire + τ_flight 的位置 )`（提前量 = 发弹延迟 + 弹道飞行时间；机构延迟由 MPC 动力学内的输入延迟显式承担）。
- **时延不确定性处理（v1 简化 → v2 增强）**：v1 用名义延迟 + 边界扰动扫描（灵敏度表）；v2 引入约束收紧（以 `Δ_i` 缩进命中窗口）或管道 MPC，并在论文中给出稳定性讨论（参照 Sensors 2024 Smith 稳定性条件思路）。

### 4.3 发弹决策（fire window）

- 命中条件：`angle(gun_dir, μ(t_fire+τ_fire+τ_flight)) + k·σ_impact < θ_hit`，`θ_hit` 由装甲板尺寸/距离换算（约 atan(0.05/0.4)≈7° 量级，真机标定）。
- 与 MPC 的关系：v1 为独立判据（每步检查）；v2 将"可射击"作为 MPC 软约束/惩罚（与 SHtech 的 `shoot_offset` 思路对齐但显式建模）。

### 4.4 弹道补偿

- 简化模型：水平匀速、铅垂面重力 + 空气阻力系数标定；`τ_flight(distance)` 查表/解析解。
- 瞄准点 = 预测目标在 `t+τ_fire+τ_flight` 的位置 + 弹道下垂修正。

## 6. 仿真平台（sim/，Phase 1 先行）

- 模块：`trajectories.py`（直线/圆周/S 形/变速）、`gimbal.py`（二阶+输入延迟）、`delay.py`（固定/时变 jitter）、`estimator.py`（KF/EKF+延迟测量）、`controllers.py`（LeadCompPID / PlainMPC / DelayAwareMPC）、`metrics.py`（角误差 RMSE、命中率、脱靶量）、`run_experiments.py`（场景×方案×随机种子）。
- 指标：**主指标**命中率（发弹数 N、裁判判定模型）、云台指向角误差 RMSE；次指标脱靶量、时延估计误差、求解耗时 P99。
- 消融：A1 去掉时延建模（=PlainMPC）；A2 去掉预测（直接瞄准）；A3 固定 vs 时变延迟注入；A4 目标运动模型；A5 与 B1 同前级复现对比。
- 统计：多随机种子、配对检验（p<0.05 + 效应量），预注册。

## 7. 真机实验协议（概要，详见 experiment_protocol.md）

1. **标定**：相机内参/外参、PNP、弹道模型、云台带宽（阶跃响应）、命中半径。
2. **延迟画像**：按 §2.3 实测各段延迟分布，≥200 样本/段。
3. **靶标装置**：已知运动规律的靶标（电机驱动旋转臂/循迹小车 + 装甲板），覆盖直线/圆周/S 形/变速。
4. **对照流程**：每方案 N 发 × M 轮（预注册，建议 N≥300、M≥3），轮次随机交叉消除漂移；裁判系统判定命中。
5. **数据记录**：全部时间戳、控制指令、云台编码器、检测输出、命中事件 → 离线重放与归因。

## 10. 风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| 新颖性被 SHtech(2026)/Barreto(2002) 覆盖 | 高 | 差异化：时变延迟显式建模 + 鲁棒性 + 受控评估；把 SHtech 当基线，诚实定位 |
