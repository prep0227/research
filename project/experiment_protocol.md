# 真机实验协议（RoboMaster 自研步兵）

- **版本**: v1.1（2026-08-11，在 v1.0 基础上增补统计功效分析、延迟注入设计与轨迹参数化）
- **前置**: 仿真 v0.3 出口准则通过（Ours 在 ≥2 类轨迹显著优于 B0/B1 且消融为正；ADMM P99<20ms）

## 1. 标定（P3 第 1-2 周）

| 项 | 方法 | 出口 |
|---|---|---|
| 相机内参/外参 | 棋盘格标定 + 手眼标定 | 重投影误差 <0.3px |
| PNP 解算 | 装甲板四点几何 | 3m 距离位置误差 <3cm |
| 弹道模型 | 不同距离/初速实弹测量弹道下坠 | 飞行时间误差 <10ms |
| 云台带宽 | 阶跃响应（多幅值/多速度档） | 辨识一阶/二阶模型 + 延迟分布 |
| 命中半径 | 装甲板几何 + 裁判系统实测 | θ_hit 标定值 |

## 2. 延迟画像（P3 第 3-4 周，每段 ≥200 样本）

- **τ_cam**：工业相机 SDK 曝光中点/结束时间戳 vs 图像到达主机时间。
- **τ_proc**：流水线逐级插桩（取图→检测→角点→PNP），ns 级时间戳。
- **τ_serial**：指令发送时间 vs 电控回执（回包时间戳）。
- **τ_gimbal**：指令时间 → 编码器/IMU 到位判据（角速度过零 + 稳定窗口）的时间。
- **τ_fire**：发弹信号 → 出膛（光电/声学触发传感器；或裁判系统发弹事件）。
- **τ_flight**：弹道模型解算 + 实测飞行时间校准。
- **输出**：`latency_profile.yaml`（各段均值/标准差/分布类型/不确定性界 Δ_i=P99−mean）。
- **真实性检查**：画像各段分布须与仿真三模式对齐（fixed≈常数；gamma≈均值±20% 随机；drift≈均值漂移 ±30%），否则调整仿真参数并重跑 v0.4。

### 2.1 延迟注入设计（受控对照的关键）

自然延迟可能过小/过于平稳，无法在真机充分区分"时延建模"贡献。采用**软件注入 + 时间戳搬移**：

- 在检测输出处注入可配置人为延迟 τ_inj(t)，并将该延迟计入"图像时间戳 → 解算时间戳"的 τ_proc 段（仿真三模式同构）：
  1. **fixed**: τ_inj = 常数（如 40ms）
  2. **gamma**: τ_inj ~ 均值 40ms、±20% 随机抖动（Gamma/均匀）
  3. **drift**: τ_inj 均值在 20–60ms 间慢漂移（周期约 10s）
- 注入在算法外部实现（独立代理进程），三种方法（B0/B1/Ours）经同一注入日志驱动 → 保证组间公平，且可精确复现。
- **归因隔离**：对每组实验保存全链路日志，B0/B1/Ours 的"检测/解算前级"完全一致，差异仅来自预测/控制/发弹决策（离线重放可复核）。
- **丢帧处理**：真机日志允许检测丢帧；补充仿真（Table S2）表明 Ours 在 0–20% 丢帧下命中率基本不变且始终显著优于 B1，丢帧不构成协议威胁。

## 3. 靶标装置与轨迹谱（与仿真对齐）

- 已知运动规律靶标：电机驱动旋转臂（圆周）、循迹小车（直线/变速）、摆动机构（S 形），载真实装甲板。
- **轨迹参数化**（与 `sim/trajectories.py` 一致）：

| 轨迹 | 参数 | 速度档位（与仿真对齐） |
|---|---|---|
| 直线 line | 匀速直行，方向随机 | 低速 0.5 / 中速 1.2 / 高速 2.0 m/s |
| 圆周 circle | 半径 R=3m，角速度恒定 | ω 对应 0.5/1.2/2.0 m/s 线速度 |
| S 形 s | 横向正弦 + 纵向匀速（A=0.5m, f=0.3Hz） | 峰值速度 0.5/1.2/2.0 m/s |
| 变速 accel | 直线 + 阶跃/斜坡变速（每 2s 变档） | 0.5↔2.0 m/s 随机切换 |

- 每个速度档位至少 1 轮；主指标按场景聚合（速度档为次要因子，报告分层结果）。
- **仿真背书**：速度档已由补充仿真覆盖（`sim/results_speed_sweep.json`，drift 模式 ×10 seeds，论文 Table S1），确保协议与仿真速度档对齐有据可查。
- 地面真值：编码器/运动捕捉（如有）记录靶标位姿；裁判系统记录命中。

## 4. 对照流程与统计（预注册）

- 方案：B0（RMVL 风格 Kt+B+PID）/ B1（SHtech 风格无时延建模 MPC）/ Ours（时延感知 MPC）。
- 每方案每场景 **N=300 发 × M=3 轮**（每方法每场景共 900 发；每场景 3 方法共 2700 发），轮次随机交叉（消除漂移/热漂移）。
- 主指标：命中率（裁判系统判定，规定发弹数）。

### 4.1 统计方法与功效分析（v1.1 新增）

- **主检验**：Ours vs B0 配对单侧 McNemar 精确检验（同一轮次内按发弹序号配对，靶标状态序列一致），α=0.05。
- **判定规则**（Gate 4 批准）：`观测提升 ≥5pp 且 p<0.05` 视为支持假设。
- **功效分析**（`project/real_power_analysis.json` / `_ext.json`，Monte Carlo，2026-08-11）：
  - 在真实效应恰为 +5pp、N=900/方法（300×3）时，**显著性检验功效 ≈0.81–0.85（ρ=0.5）至 0.95（ρ=0.8）**；
  - **注意**：`观测提升 ≥5pp` 这一门槛在真实效应恰为 5pp 时**天然饱和在 ~50% 功效**（估计量以阈值为中心），因此必须同时报告单侧 95% CI 下界与效应量，避免把"观测略低于 5pp"误判为无效应；
  - 若真实效应为 8pp，`≥5pp 且 p<0.05` 联合功效将显著上升（仿真验证见 `_ext.json`）。
- **预注册升级规则**：若首轮 p<0.05 但观测提升落在 3–5pp，追加 1 轮（N=300）以收窄 CI；预算封顶 N=1200/方法/场景。
- 次指标：云台指向角误差 RMSE（编码器真值）、脱靶量、时延估计误差、MPC 求解耗时 P99（须 < 控制周期）。

## 5. 数据记录与归因

- 全链路时间戳日志：曝光、取图、检测、解算、指令发送、电控接收、云台到位、发弹、命中。
- 离线重放：任意方案可在同一日志上重放控制律（同前级检测/解算输出）→ 隔离"控制/补偿"贡献。
- 消融在真机的最小集：A1（去掉时延建模）、A3（固定 vs 真实时变延迟）——A2/A4/A5 以仿真为主，真机复核。

## 6. 失败条件（预注册）

1. 时延测量协议达不到 1ms 级精度 → 实验无效，回退仿真+半实物。
2. Ours 在 ≥2 个场景未达到 `p<0.05 且（观测提升≥5pp 或单侧 95% CI 下界≥3pp）` → 假设不成立，改写论文定位（如仅"跟踪误差"指标）。
3. MPC 求解 P99 > 控制周期 → 降 H/降采样或换求解器，仍不达标则判方法不可部署（论文改为讨论）。

## 7. 装备清单与时间预算

- 硬件：自研步兵（全向轮+两轴云台+工业相机）、裁判系统、靶标装置×3、光电/声学出膛触发器、备用弹仓。
- 软件：`tools/delay_profiler/`（画像）、`sim/`（离线重放）、`deploy/cpp/mpc_solver.hpp`（嵌入式求解器）。
