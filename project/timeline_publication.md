## 发表策略

### 英文期刊（首选）
| 期刊 | 匹配度 | 理由/风险 |
|---|---|---|
| IEEE Robotics and Automation Letters (RA-L) | 高 | 机器人控制+视觉伺服；需要真机实验，篇幅短 |
| Journal of Intelligent & Robotic Systems | 高 | 平台+方法均可；审稿适中 |
| Control Engineering Practice | 中高 | 强调工程实践与可复现；需要扎实真机数据 |
| MDPI Actuators / Sensors | 中 | 已有光电跟踪/延迟补偿先例（Actuators 2023 等），周期快 |
| IEEE Access | 中 | 兜底英文（开源友好） |

### 中文核心（兜底）
- 兵工学报 / 兵器装备工程学报（已有 RM 自瞄先例：2022 哈工程）
- 机器人 / 自动化学报（控制+机器人）

### 投稿卖点（差异化定位，规避 SHtech/Barreto 先例）
1. **时变/不确定延迟链的显式建模 + 在线估计**（SHtech 用常量参数，Barreto 为 2002 年框架）。
2. **延迟感知 MPC 的受控消融归因**：延迟建模 vs 目标模型 vs 弹道模型（社区无此定量证据）。
3. **可复现交付**：仿真代码 + 真机数据集 + 延迟画像（形成基准贡献 gap_benchmark）。

## 风险对策（与 technical_route §10 对应）

- 时间不足 → 论文先写"方法+仿真"，真机作为追加章节；兜底中文核心。
- 真机显著性问题 → 预注册大样本 + 配对设计；主指标失败时退级"跟踪误差"指标并如实报告。
